# Barberry Garden tap

Homebrew formulae for [Barberry Garden](https://barberry.io).

## barberry

`barberry` is the Barberry Garden command line: search the catalog, read your tasting notes and the
ones Barberry published, and export them for an assistant to read.

```sh
brew install barberry-io/tap/barberry
barberry login
```

The command line works for members who were given access to it. Builds are published here as
releases; the source lives elsewhere.
